# Shifumi

Jeu de pierre-feuille-ciseaux jouable contre un bot, avec suivi du score en temps réel.

🔗 **Voir le projet en ligne :** https://simclement.github.io/UltimateShifumi/

## 📖 Contexte

Projet développé dans le cadre d'un cours de JavaScript, dont l'objectif était d'apprendre les principes fondamentaux du langage (manipulation du DOM, gestion d'événements, logique de jeu).

## ✨ Fonctionnalités

- Choix entre **Pierre**, **Feuille** et **Ciseaux** via trois boutons cliquables
- Affrontement contre un **bot** jouant un coup aléatoire
- Affichage du coup choisi par le bot et du résultat de la manche (victoire / égalité / défaite)
- **Score cumulé** sur la partie : total de victoires, d'égalités et de défaites

## 🛠️ Langages et technologies utilisés

- HTML
- CSS
- JavaScript (vanilla)
